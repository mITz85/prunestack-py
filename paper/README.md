# Reproducing the manuscript

Results and analysis scripts for the manuscript *Does Diversity Help Ensemble Pruning?
A Nested-Evaluation Study of Performance–Diversity Trade-offs in Heterogeneous Ensembles*
(M. Domladovac). All numbers in the manuscript were produced with PruneStack 2.2.0.

## Contents

| Path | Content |
|---|---|
| `datasets.csv` | The 21 datasets (8 classification, 13 regression): id, task, target, n, p after cleaning, title and source URL |
| `data/<id>/results/` | Output of `prunestack --protocol nested` for each dataset (30 runs, 5 outer folds, α ∈ {0, 0.1, ..., 1}) |
| `scripts/final21.py` | RQ1 to RQ3: W/T/L, Wilcoxon tests, Holm correction, fixed-α and leave-one-dataset-out comparisons |
| `scripts/selection_bias.py` | Section 4.2.4: on-target vs split-run α\*, permutation null (seed 1985) |
| `scripts/rq4_and_sizes.py` | Section 4.1 ensemble sizes and Section 4.4 / Table 9 (Mann–Whitney, Spearman, Holm) |
| `scripts/make_figures.py` | Figures 1 to 4 (EPS, TIFF, PDF, PNG) into `paper/figures/` |
| `expected_output/` | The console output of each script, for comparison |

### Files per dataset (`data/<id>/results/`)

| File | Content |
|---|---|
| `summary.json` | Package version, task, n, p, dropped columns, full resolved configuration, run times |
| `heldout_performance.csv` | Held-out score of every strategy (pruned vote / pruned stacked per run and α; full vote, full stacked, best single) |
| `selection.csv` | Every selected subset (run, fold, α, member indices, inner fitness, performance and diversity, held-out scores) |
| `alpha_curve.csv`, `alpha_star.json` | Mean α-curve over runs and the per-dataset α\* (descriptive only) |
| `meta_features.json` | The 123 dataset and pool meta-features (inner predictions) |
| `fitness_normalization.json` | Bounds used to normalise P and D in each of the five outer folds |
| `base_models/model_pool.json` | The 120 base models: algorithm, fixed hyperparameters and feature subset |

Not included, because they are large and are regenerated by the package: per-fold model
checkpoints (`folds/*.npz`), base-model held-out predictions and run logs.

## Recomputing the tables and figures

Python 3.15 and the pinned environment of the repository:

```bash
python3.15 -m venv .venv && source .venv/bin/activate
pip install -r requirements-lock.txt && pip install -e . --no-deps
python paper/scripts/final21.py          > final21.txt
python paper/scripts/selection_bias.py   > selection_bias.txt
python paper/scripts/rq4_and_sizes.py    > rq4_and_sizes.txt
python paper/scripts/make_figures.py     # writes paper/figures/
diff final21.txt paper/expected_output/final21.txt
```

Each script accepts another results root as its first argument (`make_figures.py`:
`--data-root`), with the layout `<root>/<id>/results/`, so it can be applied to a fresh run.
The analysis scripts need only numpy, pandas, scipy, matplotlib and pillow.

## Re-running the experiment

The source datasets are published by their authors (mostly in *Data in Brief*; dataset 1
in the UCI Machine Learning Repository) and are not redistributed here; see
`datasets.csv`. Each dataset directory must contain `X_test.csv`, `y_test.csv` and
`metrics.csv` (see `docs/quickstart.md`). Datasets 73 and 74 are the two disjoint hotels
(H1 resort, H2 city) of the same source. Dataset 52 uses `configs/datasets/52.yaml`.

```bash
DATASETS_FILE=configs/datasets_final.txt scripts/run_all.sh DATA_ROOT 4 30
python paper/scripts/final21.py DATA_ROOT
```

All randomness derives from fixed seeds (base seed 1985 for folds, feature subsets and
models; optimisation runs use seeds 1 to 30). A re-run with the pinned environment is
expected to reproduce the result files; bit-level identity across operating systems and
BLAS builds is not guaranteed.
